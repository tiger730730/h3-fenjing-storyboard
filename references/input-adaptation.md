# 工作流 0：输入适配层（想法 / 描述 / 网文 → H3 分镜）

> 本文是 `h3-fenjing-storyboard` 的**前置适配层**。作用是让用户"丢一个想法、一段描述、甚至一整篇网文"就能直接产出 MiniMax H3 分镜：先把原始素材解析成工作流 A/B/C 能直接使用的结构化输入，再对长内容自动分段并路由到对应工作流。选择流程时先读本文，完成解析与分段后再读目标工作流的权威规则（`references/template-full.md` / `jiugongge-9grid.md` / `sanliucheng-3process.md`）。

## 0.1 输入类型识别

先判断用户给的是什么，决定解析深度：

| 输入类型 | 特征 | 解析方式 |
| --- | --- | --- |
| **一句话想法** | 一两句话，无细节 | 最低限度合理推测：补足主体、场景、情绪、风格，锁定后不再变。 |
| **段落描述** | 一段场景/剧情/人物描写 | 中等解析：提取人物、场景、关键动作、对白、情绪、风格。 |
| **短剧本/脚本** | 已有分场或分镜雏形 | 直接采纳其场次/镜头划分，补结构化字段。 |
| **网文（长）** | 多章/长篇连载 | 深度解析 + **自动分段**（见 0.3），按剧情转折切成多个分镜单元。 |

规则：能复用的素材绝不要求用户重发；缺美术细节时自行合理决定并**锁定**，不把用户拦在连续选择题前。仅当信息实质改变成片且无法推断时才补问一个简短问题。

## 0.2 解析产出：结构化输入字段

无论输入多粗糙，都解析并输出以下字段（作为后续工作流 A/B/C 的 `{{...}}` 输入）。缺省字段用合理推测补足并标注"推测并锁定"。

- **故事情节**：全局剧情概述（谁、在哪、发生什么、结果）。
- **输入文案**：当前分镜单元的**核心文案**（工作流 A 中对白唯一来源；B/C 的事件主干）。长内容按 0.3 分段后，每段各产出一条输入文案。
- **角色信息**：姓名、年龄（无则推测并锁定）、性别、外形/发型/服饰/识别点、性格、稳定外观。含**角色音色**（性别/年龄/音色质感，无则按角色推断）。
- **场景信息**：地点、时间、天气、空间结构、主光方向、关键陈设。
- **物品信息**：关键道具的轮廓/材质/状态。
- **风格基调**：题材、时代感、镜头语言倾向、色彩/光线倾向（供视觉风格段/风格圣经用）。
- **对白清单**：原文逐句摘出，标注说话者、语言、情绪（供文戏与各工作流使用）。
- **推荐工作流**：见 0.4。

## 0.3 长网文自动分段（分段算法）

把长内容切成若干"一个分镜单元"（工作流 A=10秒/组，B=15秒/板，C=按时长）的规则：

1. **按剧情转折切**：一个完整"事件节拍"（建立→冲突→转折→结果）为一段，不在对白/动作中途硬切。
2. **每段定锚**：每段取一个稳定主体 + 一条视觉发展线 + 明确起止状态，保证段与段可衔接（继承上一段末态、为下一段铺路）。
3. **对白承载**：每段对白量须能放入该时长预算（A:4~4.5字/秒、B:约3字/秒、C:按时长档），放不下就再切。
4. **逐段输出输入文案**：每段对应一条 `输入文案`，供工作流逐段生成。
5. **状态台账**：角色位置/朝向/道具状态/服装/光线/时间在段间延续，不重置（呼应工作流 A 状态交接规则）。
6. 分段后向用户展示：总段数、每段时长、每段一句摘要、预计提示词数量、总时长估算；确认后逐段生成。

## 0.4 工作流推荐路由

解析后按输入形态推荐，并可与用户确认：

| 场景 | 推荐工作流 |
| --- | --- |
| 一句话想法 / 段落描述，想要**快速单条**直接可贴 → | **C（三流程）**，确认时长 5/10/15 秒与文戏/武戏/九宫格 |
| 有明确多角色+场景库、要**严格资产一致性**（三视图/场景三方向）→ | **A（默认10秒两段式）**，先出资产再分镜 |
| 要**电影级导演流程**（角色Sheet/风格圣经/九宫格母版）→ | **B（9宫格导演15秒）** |
| 长网文整篇 → | 先用 0.3 分段，再按每段性质选 A/B/C（推荐 B 或 C 逐段产出） |

## 0.5 执行步骤（入口统一走这里）

1. 读本文，识别输入类型（想法/描述/短剧本/网文）。
2. 执行 0.2 解析，产出全部结构化字段（缺失项合理推测并锁定）。
3. 若为长内容，按 0.3 分段并展示分段概览，等确认。
4. 按 0.4 推荐并确认工作流与时长。
5. 读取对应工作流权威规则（A/B/C），代入 `{{...}}` 输入逐段生成分镜。
6. 遵循该工作流自带的自检清单收尾。
