# h3-fenjing-storyboard

为 **MiniMax H3** 视频生成分镜的全流程生成器。接受一句话想法、段落描述、短剧本甚至整篇网文，自动解析为结构化输入，并路由到多套工作流产出 H3 分镜。

> 定位：**内容层 / 导演层** —— 负责"拍什么、怎么切"，从素材构思完整分镜（资产、宫格、对白节奏、正反打、运镜、降敏）。

## 它能做什么

- 丢一个想法 / 一段描述 / 一篇网文 → 自动解析角色、场景、物品、对白 → 直接出 H3 分镜。
- 长网文**自动分段**成多个分镜单元，段间状态台账延续。
- 内置三套生成工作流，覆盖主流 H3 分镜范式。
- 仅用于 **MiniMax H3**，不衔接 Seedance。

## 目录结构

```
h3-fenjing-storyboard/
├── SKILL.md                          # 技能入口：工作流路由 + 各流程速查
└── references/
    ├── input-adaptation.md           # 工作流0：输入适配层（想法/描述/网文→结构化字段+分段+路由）
    ├── template-full.md              # 工作流A：默认10秒两段式（2×3宫格 sc1~sc6，资产阶段→分镜阶段）
    ├── jiugongge-9grid.md            # 工作流B：9宫格导演（3×3 P01~P09，15秒/板，角色Sheet+风格圣经）
    └── sanliucheng-3process.md       # 工作流C：三流程模板（文戏/武戏/九宫格，5/10/15秒）
```

## 四套工作流

| 工作流 | 作用 | 参考文件 |
| --- | --- | --- |
| **0. 输入适配层** | 把想法/描述/网文解析成角色/场景/物品/对白字段；长网文自动分段；推荐并确认工作流 | `input-adaptation.md` |
| **A. 默认10秒两段式** | 2×3 宫格（sc1~sc6），资产阶段→分镜阶段，10秒/组 | `template-full.md` |
| **B. 9宫格导演** | 3×3 九宫格（P01~P09），15秒/板，含角色Sheet/风格圣经/连续性自检 | `jiugongge-9grid.md` |
| **C. 三流程模板** | 文戏/武戏/九宫格三选一，5/10/15秒/条，单条自然语言提示词 | `sanliucheng-3process.md` |

**流程速查：**
- 「10秒、sc1-sc6、2×3、资产阶段」→ 工作流 A。
- 「九宫格导演、15秒、P01-P09、角色Sheet、风格圣经」→ 工作流 B。
- 「文戏、武戏、5秒、直接给一条」→ 工作流 C。
- 「想法/描述/网文」→ 先走**工作流0** 解析+分段，再路由。
- 未明确时，先走工作流0 解析，再与用户确认。

## 典型链路

```
想法/描述/网文
   ↓ 工作流0 解析+分段
角色/场景/物品/对白 结构化输入
   ↓ 路由
A. 默认10秒两段式 │ B. 9宫格导演15秒 │ C. 三流程5/10/15秒
   ↓
MiniMax H3 分镜提示词
```

## 与 h3-prompt-writing 的分工

| | h3-fenjing-storyboard | h3-prompt-writing |
| --- | --- | --- |
| 管什么 | **拍什么、怎么切**（分镜/资产/节奏） | **怎么符合 H3 语法**（字段/标签/时间码） |
| 输出 | 叙事完整的分镜草稿 | H3 官方语法提示词 |
| 建议用法 | 先出内容 | 套格式 |

**推荐搭配**：先用本技能从想法/网文产出分镜内容，再交给 `h3-prompt-writing` 套成 H3 官方语法直接提交。

## 使用方式

- 直接作为系统提示词或项目工作流说明使用。
- 将 `{{...}}` 占位内容替换为实际项目信息。
- 入口统一走工作流0，再由它路由到 A/B/C。
